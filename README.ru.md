# Patchnotes

**Патчноуты для страны.** Patchnotes отслеживает все изменения законодательства Германии — федеральные
законы и постановления, законы всех 16 земель, законопроекты Бундестага, — хранит тексты законов в
формате Markdown в открытом git-репозитории (каждое изменение закона — это Pull Request), объясняет с
помощью ИИ простым языком, что именно изменилось, переводит на **русский, украинский, английский и
турецкий** и уведомляет каждого человека о том, что касается именно его: с учётом статуса пребывания,
земли, работы, семьи и других тегов профиля.

Проект сделан для людей, которые живут в Германии и не читают по-немецки.

> Это информация, а не юридическая консультация. Юридическую силу имеет только немецкий текст.

- **Требования:** `docs/SPEC.md` (единственный источник истины)
- **Прогресс:** `docs/PROGRESS.md`
- **Решения:** `docs/adr/`

## Статус

В активной разработке, по этапам (SPEC.md § 20). Текущее состояние — в `docs/PROGRESS.md`.

## Быстрый старт (разработка)

Нужен только Docker (Desktop или Engine) с Compose v2:

```bash
git clone <этот репозиторий> patchnotes && cd patchnotes
cp .env .env.local          # по желанию: реальные секреты кладутся в .env.local
make up                     # поднять стек
make install                # зависимости, ключи, база данных, ассеты
open https://localhost/      # в разработке — самоподписанный сертификат
```

Полезные адреса: `https://localhost/healthz` (liveness), `https://localhost/readyz` (readiness),
`http://localhost:8025` (Mailpit — перехваченная почта).

Без ключей ИИ система тоже работает: источники синхронизируются, репозиторий `laws` наполняется, а
задачи, которым нужен ИИ (карточки, переводы), ждут в очереди до появления провайдера. Команда
`make demo` показывает полностью рабочий сайт на фикстурах — без сети и без ключей.

## Как это устроено

```
источники (gesetze-im-internet, BGBl, DIP, порталы 16 земель)
   → нормализация в Markdown (детерминированная, без ИИ)
   → git-репозиторий «laws» (один акт-поправка = один Pull Request)
   → ИИ: анализ, факты, теги аудитории, карточка простым языком, переводы, проверка
   → git-репозиторий «content» (facts.yml + карточки на 4 языках)
   → сайт, поиск, персональная лента
   → уведомления: email, Telegram, Web Push, iCal, RSS
```

Задействованы три репозитория: этот (код приложения, AGPL-3.0), `laws` (тексты законов, CC0) и
`content` (карточки и переводы, CC BY 4.0). Источник правды для контента — git; MySQL — это кэш плюс
данные пользователей, которые в git не попадают никогда.
